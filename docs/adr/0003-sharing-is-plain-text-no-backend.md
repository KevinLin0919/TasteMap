# 分享用純文字，不建後端

推薦清單以純文字（可選圖片）分享，貼進 LINE 或訊息即可，不提供公開網頁連結。每間店附上以 `place_id` 組成的官方 Google Maps 連結 —— `place_id` 恰好是條款允許永久保存的唯一外部資料，也恰好是分享唯一需要的資料。

## Considered Options

公開網頁連結（原 ROADMAP M4 的方向）被否決：它使 TasteMap 從自用 app 變成託管使用者內容的服務，帶來伺服器成本、連結永久性、轉發控制與刪除權等責任，而相對於「一段能貼進 LINE 的文字」，對收訊者的價值增加有限。純文字的收訊者不需安裝 app、不需註冊、不需開瀏覽器。

## Consequences

ROADMAP M4 中為分享而存在的部分（VPS API、加密傳輸、公開推薦卡片與清單）全部移除。M4 僅剩「換裝置不遺失資料」的備份需求，那是與分享無關的另一個問題，不應綁在一起。

分享內容為 Place 名稱、分數、Dish 與 Pitch。Note 永不包含在內。
